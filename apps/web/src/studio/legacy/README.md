# Legacy Phase 19 Studio

The pre-reset Phase 19 Studio UX is archived conceptually here.

The active Studio entry is now visual-builder-first:

- `/studio` opens RediOS Visual Builder.
- `/studio/builder/web` opens web layout builder.
- `/studio/builder/android` opens Android layout builder.
- `/studio/metadata` opens the advanced metadata designer.

Old guided wizard, metadata-first, screen-designer, and API-first flows should not be used as primary user experience. Keep any remaining legacy files only as compatibility code until their imports are fully removed.
