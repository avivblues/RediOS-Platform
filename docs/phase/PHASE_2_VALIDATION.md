## API

```bash
# Persona with dynamically merged capabilities
curl -H "Authorization: Bearer $TOKEN" http://localhost:3041/api/experience/persona

# SSE notification stream (EventSource; pass token query param)
curl -N -H "Accept: text/event-stream" \
  "http://localhost:3041/api/experience/notifications/stream?token=$TOKEN"

# Process HUMAN_TASK: START work order creates inbox task from metadata step
curl -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  http://localhost:3041/api/runtime/WORK_ORDER/{id}/actions/START -d '{}'
```

Persona metadata seeded under `applicationCode=REDIOS_PLATFORM`, type `PERSONA` (4 personas).

Capabilities merge: persona metadata base + JWT role permissions (`*` expands to platform/metadata/builder/runtime wildcards).
